    本原型未演示的分支

    按约定只做主流程（Premium + 服务端成功回执），以下分支以文字为准，需要时再补原型。

    免费用户点 Keep

    打开订阅页。关闭订阅页回到是否保留数据选择页；付费成功自动进入二维码界面；买团队订阅先走团队流程，再自动进入二维码界面。

    二维码不可用

    loading 下二维码已过期，或扫码时导出设备未在前台展示二维码 → 弹层 QR Code Expired（标题带橙色警告图标），点 OK / 返回键 / 空白处关闭，停留在扫码页。

    导出失败

    其他异常导致失败 → 橙色 toast Something wrong, please try again. 两端均不删除数据。

    取消导出

    A 端 Cancel、B 端关闭 loading 均视为取消，需回调服务端；B 端不写入任何数据。

    重复数据处理

    服务端确认成功导出后开始处理：先依次弹 code 重复数据，再弹 password 重复数据，全部处理完才跳首页出成功 toast。

    Remove 后的数据

    移除的数据进入最近删除，可恢复；免费用户的恢复走付费。Remove 只在 S5 回执确认后执行。

    关闭 loading

    A 端 loading 点 ✕ 或返回键可关闭，不影响最终导出结果；结果回来时该出的弹层照出。

    待确认

    二维码是否需要过期逻辑以服务端为准；分类关系与收藏状态随本次迁移一并写入，列表不展示。
